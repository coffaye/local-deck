# 界面证据

- `demo/`：通过 `--demo` 生成的界面预览。硬件、Codex、DeepSeek 数值均为演示数据。
- `real/`：从本机真实运行捕获。硬件和 Codex 额度为真实数据；DeepSeek 未配置 Key。

当前 1.4.3 为 **360 × 360** 的 1:1 方形挂件：顶部标签与窗口按钮无外框；
左上角与任务栏共用霓虹 77 Logo；三个页面不再有页头标题；
CPU / 内存分段格在同一行；额度信息改为底部条带，`2 次重置可用` 下方无大块空白；
设置中可选 1 / 2 / 5 / 10 秒硬件刷新；保存按钮完整显示；
顶部只有检测台与设置两个入口；检测台增加核显/独显两路 GPU；顶栏图钉左侧为短透明度滑条。
