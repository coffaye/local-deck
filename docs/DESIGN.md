# 桌仪 · LocalDeck 设计说明

日期：2026-11-19

## 北极星

一块放在桌面角落的深夜电量表：360 × 360 的方形迷你仪表，而不是一个网页窗口。信息压缩到一眼能扫完，电光只在关键读数上出现。

## 产品事实

- **用户**：一台 Windows 11 笔记本的个人使用者。
- **任务**：快速查看本机负载、温度、网速，以及 Codex 和 DeepSeek 两份 AI 账户额度。
- **运行限制**：直接运行 exe；不需要管理员；不能依赖浏览器或脚本运行时；只能读取本机数据；额度请求必须是只读的。
- **尺寸**：用户要求整体 1:1，固定为 **360 × 360**；布局顺序不变，增加纵向空间。

## 方向与取舍

**选定方向**：深紫机身 + 近黑 LCD + 极紧凑的霓虹读数。大留白被去掉，所有信息在单屏内完成。

色板：

- 机身 / 面板底色：`#12003b`
- 屏幕 / 深底：`#0a0a0f`
- 主操作 / 活动态 / 警示：`#ff007f`
- 主读数 / 正常状态：`#00f0ff`
- 金额 / 次要强调：`#ffef00`

视觉选择：

- 数字继续使用 DSEG7 Classic Bold Italic；中文用 Microsoft YaHei UI；速率用 Cascadia Mono。
- 温度 / 核显 / 独显 / 网络四列同高；独显温度用 `℃`，CPU 温度保留 `°C`。核显使用 LibreHardwareMonitor 的 D3D 3D 负载；Radeon 780M 没有独立温度传感器时显示 `—`。
- 顶部只保留：77 霓虹 Logo + 桌仪字标、两个纯文字标签、图钉左侧的 52px 横向背景透明度滑条、三个无外框线框按钮（图钉 / 最小化 / 关闭）。
- 透明度滑条只改变背景层 `Backdrop` 的 alpha；窗口 `AllowsTransparency=True`，文字和控件保持完全不透明。最小 35%，最大 100%。
- 点击 X 隐藏到系统托盘；左键打开，右键系统原生菜单退出；点击菜单外会关闭。托盘悬停只显示「桌仪」。Windows 11 新图标默认进入 `^` 隐藏区，程序会尝试常显；系统拒绝托盘注册时退化为最小化到任务栏。
- 设置路径优先使用 exe 旁已有的 `LocalDeck-data`，避免权限变化时切到没有密钥的 AppData。
- 77 Logo 使用深紫底、品红边、青色数字、黄色状态点；去掉数字下方的 5 条短线。
- 页面不再有页头标题；内容从顶栏下方直接开始，顶栏三个纯文字标签表示当前页面。没有页码、英文副标题、`LOCAL` 状态或右侧圆点 + 线。
- CPU / 内存使用同一个 4 行网格：标签、数字、分段格、辅助信息；两条分段格严格同高对齐。
- 额度不再做独立右侧高栏，改为底部横向条带；Codex 的 5h / 7d、重置信息和 DeepSeek 余额连续排列，消除「2 次重置可用」下方的大段空白。
- 设置采用「数据源 / 刷新 / 窗口」三组卡片：Codex 路径、DeepSeek 密钥、三个下拉框、三个开关、保存按钮，铺满方形页面；保存按钮完整显示。
- 保存后的 DeepSeek 密钥不回显；输入框留空是安全设计，设置页显示「密钥已保存 · 留空不修改」。
- 构建时保留 `LocalDeck-data`，避免维护过程清掉 DPAPI 密钥；Windows 图标缓存通过启动通知与刷新脚本处理。
- 硬件传感器初始化（尤其 LibreHardwareMonitor 的硬件扫描）放在后台，不阻塞首帧；窗口先显示，GPU 数据随后补齐。
- 分发 exe 重新标记为 Medium 完整性，并提供解除下载阻止的 `启动桌仪.cmd`。
- 历史曲线被压缩成一条无文字的双线带；只表达趋势，不占注意力。

## 页面结构

- **检测台 · 性能优先（默认）**：CPU / 内存双读数 → 极简历史带 → 温度 / 核显 / 独显 / 网络 → Codex + Claude + DeepSeek 三条额度区。没有页头标题，页面从顶栏下直接开始。
- **检测台 · 额度优先**：额度条置于顶部并放大数字；Codex 的「5 小时 / 7 天」标签保持在数值上方，0% / 100% 大数字回调到与 DeepSeek 余额平衡的位置；CPU / 内存缩小；历史曲线缩短；传感器行留底部。只换布局与字号，不换数据源。
- **设置页**：内容可滚动，底部固定「保存并应用」栏，避免小窗口/缩放下按钮被裁切。
- 窗口为 360 × 360 方形；短透明度滑条位于顶栏图钉左侧。
- **设置**：Codex 路径、DeepSeek 密钥、统计网卡、额度刷新、硬件刷新、窗口置顶、开机启动、标题栏隐藏、保存。
- 「标题栏隐藏」勾选并保存后，窗口失焦时整块窗框上沿下移 30px、窗口高度缩短 30px；正文保持 330px，内容屏幕位置不变。重新聚焦恢复，不留空白条。
- 不再提供单独的额度页；额度摘要固定在检测台底部。

## 状态

- Codex：正常、额度偏低、已用尽、HTTP 回退、本地缓存、不可用。
- DeepSeek：未配置、读取中、可用、余额不足、Key 无效、网络失败。
- 硬件：温度 / GPU 不可用时显示 `—`，不伪造数值。

## 动效

- 页面切换 180ms 淡入。
- CPU / 内存数字更新时 260ms 的轻微淡入。
- 不再使用大面积辉光和循环图表动画；小尺寸下优先清晰。
- 顶部没有常驻呼吸圆点。

## 数据来源

- CPU / 内存：kernel32；温度：PDH ACPI 热区；GPU：NVML；网络：NetworkInterface。
- Codex：app-server → HTTP 登录态 → 本地 JSONL 快照。只读，不刷新 token、不消费重置次数。
- DeepSeek：官方 `/user/balance`。API Key 使用 DPAPI。
- 设置：`%APPDATA%\LocalDeck`，不可写时回退到 exe 同目录。

## 验证

- `--selftest`：DPAPI、格式化、三种 Codex 解析、DeepSeek 解析、硬件采样。
- 通过内置 `--capture` 用 WPF 离屏渲染获得真实界面截图，避免受桌面遮挡影响。
- 检查视口：360 × 360（固定）、1×、1.5×、2× DPI。
- 设计证据：`screenshots/`。

## 没做的

- 不做窗口缩放；固定 360 × 360，只允许拖动。
- 不显示 CPU package 温度（需要内核驱动 / 管理员）。
- 不接入 AMD / Intel 核显。
- 不主动消耗 Codex 重置次数，也不提供“重置”按钮。
- 没有代码签名，因此首次运行可能出现 SmartScreen 提示。
