桌仪 LocalDeck 1.7.0 — 启动说明
================================

本次为 360 × 360 的 1:1 方形挂件：
左上角与任务栏共用同一枚霓虹 77 Logo；顶部标签和窗口按钮没有外框；
设置里可以选择 CPU / GPU / 温度 / 网络的刷新间隔。
本次去掉了「额度」标签页，只保留检测台和设置；检测台新增核显/独显两路 GPU 读数。
DeepSeek 密钥保存后输入框会留空显示，这是正常的安全行为；
留空保存不会清除密钥，设置页会显示「密钥已保存 · 留空不修改」。

注意：如果你之前下载过约 63 MB 的 LocalDeck.exe，那是旧版（需要 Temp
解压，可能无窗口退出）。请删除旧文件，使用本次约 2.3 MB 的新文件。

1. 推荐双击同目录的「启动桌仪.cmd」启动：
   它会解除下载阻止、设置为普通权限并启动 LocalDeck.exe。
   直接双击 LocalDeck.exe 也可以；首次可能被 SmartScreen 拦截，
   点「更多信息」→「仍要运行」即可；程序运行后会自动解除后续阻止。

2. 这是单文件主程序，需要系统已安装「.NET 8 Desktop Runtime」。
   本机已经安装，所以直接运行即可。
   如果提示缺少 .NET，或想在别的电脑上不装运行时直接运行：
   打开 LocalDeck-portable 文件夹，双击里面的 LocalDeck.exe。
   注意：必须保留 LocalDeck-portable 文件夹里的所有 DLL，不能只单独复制 exe。

3. 如果 Windows 弹出 SmartScreen「Windows 已保护你的电脑」：
   点「更多信息」→「仍要运行」。
   程序未做商业代码签名，所以会出现这个提示，但不再依赖 Temp 解压，
   点击允许后应当正常出现窗口。

4. 重复双击会切回已经打开的窗口，不会重复开后台进程。
   点击右上角 X 只会隐藏到右下角系统托盘（与电池/时间同一区域）：
   左键托盘图标重新打开；右键菜单选择「退出」才真正退出。
   Windows 11 可能把新图标收进任务栏的 ^ 里；首次隐藏会提示，
   点开 ^ 把 77 图标拖到电池/时间旁一次即可固定。
   如果系统拒绝托盘注册（低权限沙箱），会退化为最小化到任务栏；
   请从资源管理器用「启动桌仪.cmd」重新启动。

5. Windows 任务管理器中的「后台进程」是「没有可见窗口的进程」分组，
   不是待处理任务队列。svchost、浏览器辅助进程、输入法等都在里面，
   数量多是正常的。桌仪正常只运行一个 LocalDeck 进程，没有常驻服务。

6. 如果启动后仍然没有窗口，请查看同目录的 LocalDeck-error.log；
   并把该文件内容发回来。

7. 顶部图钉左侧的短滑条调整的是背景透明度：只让背景变透，
   文字和控件不会一起变暗。设置里的「标题栏隐藏」勾选并保存后，
   窗口失焦时整块窗框上沿下移并缩短窗口高度，正文位置不变；
   重新聚焦时标题栏恢复，不会留空白条。
   启动时窗口会先出现，核显传感器在后台初始化，通常几秒内补齐。
8. 更新后如暂时看不到 DeepSeek 余额，重新启动即可：旧密钥已保留，
   程序会优先读取 exe 旁的 LocalDeck-data，并同步恢复了 AppData 中的密文。
9. 托盘悬停只显示「桌仪」；右键菜单为系统原生菜单，点外面即关闭。
10. Claude 余额会自动读取 Claude CLI 配置；设置 → 数据源 → Claude 可覆盖查询地址 / Key。
11. Gemini 额度通过本机官方 Antigravity CLI（agy）只读查询 /usage；可在设置 → 数据源 → Gemini (agy) 路径中自动检测、浏览或测试。
12. 设置 → 窗口右侧的「主题」可选「性能优先 / 额度优先」；
    性能优先保持硬件在上、2×2 额度区在下，额度优先把 2×2 额度区放大并放到顶部。
13. Windows 里仍显示旧图标时：先运行「刷新Windows图标.cmd」；
   任务栏若固定过旧图标，请取消固定，再从新的 LocalDeck.exe 重新固定。
